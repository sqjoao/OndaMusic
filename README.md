# Onda

Player pessoal para **Windows 10/11 de 64 bits**, com instalador próprio.

## Instalar pelo terminal

Abra o **PowerShell** e execute:

```powershell
irm https://raw.githubusercontent.com/sqjoao/OndaMusic/main/install.ps1 | iex
```

## Biblioteca

No app, clique em **Escolher pasta** e indique onde guarda suas músicas. A escolha fica salva neste PC; subpastas também são lidas. Novos arquivos aparecem automaticamente, e o botão **Atualizar biblioteca** permite refazer a leitura quando necessário.

O Onda lê os arquivos diretamente, sem copiá-los para o app ou colocá-los no instalador. Para adicionar músicas, basta colocá-las na pasta escolhida — não precisa reinstalar. Os áudios continuam ocupando espaço em disco; ZIP costuma reduzir pouco MP3, M4A e FLAC, que já são comprimidos.

Favoritos, playlists e aparência ficam no perfil do app. Músicas importadas por versões anteriores são preservadas; o app não apaga arquivos da pasta. Em outro PC, selecione a pasta de músicas que estiver disponível nele.
